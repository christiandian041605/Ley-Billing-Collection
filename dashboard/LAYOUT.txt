Dashboard Layout Structure
==========================

Header: "Dashboard" with Breadcrumbs
====================================

Row 1: Main Statistics (4 Columns)
-----------------------------------
[Users]    [SDPs]    [Accomplishments]    [Objectives]
 Blue      Green         Yellow               Red

Row 2: Secondary Statistics (3 Columns)
----------------------------------------
[Offices]         [Targets]         [Completion %]
  Cyan             Gray                 Dark

Row 3: Charts (2 Columns - 50/50 split)
----------------------------------------
[Quarterly Progress Chart]    [Top Performing Offices]
     Bar Chart                      Table

Row 4: Data Tables (2 Columns - 50/50 split)
---------------------------------------------
[SDPs with Most Targets]      [Recent Activity Feed]
        Table                      List Group

Row 5: Analytics (2 Columns - 50/50 split)
-------------------------------------------
[Role Distribution Chart]     [System Information]
      Pie Chart                   Info Panel

Each Card Features:
===================
- Colored outline (primary, success, warning, danger, info, secondary)
- Icon in header
- Responsive design
- Quick action links

Chart.js Integration:
=====================
- CDN loaded from jsdelivr
- Responsive charts
- Interactive tooltips
- Legend positioning

All Components:
===============
- Follow AdminLTE 4 design patterns
- Use Bootstrap 5 classes
- Bootstrap Icons for all icons
- Fully responsive (desktop, tablet, mobile)
- Clean, professional appearance
