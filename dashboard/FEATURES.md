# Dashboard Features Summary

## 📊 Visual Components

### Info Boxes (Small Boxes)
1. **Total Users** - Blue box with people icon
2. **Strategic Development Plans** - Green box with list icon
3. **Total Accomplishments** - Yellow box with trophy icon
4. **Institutional Objectives** - Red box with journal icon
5. **Offices/Units** - Cyan box with diagram icon
6. **Total Targets Set** - Gray box with bullseye icon
7. **Completion Rate** - Dark box with graph icon (calculated percentage)

### Charts
1. **Quarterly Progress** (Bar Chart)
   - Compares Targets vs Accomplishments
   - Shows current year data
   - Grouped by quarters (Q1, Q2, Q3, Q4)

2. **User Role Distribution** (Pie Chart)
   - Shows breakdown of users by role
   - Admin, Faculty, Staff, Dean, Director

### Data Tables
1. **Top Performing Offices**
   - Ranked by accomplishment count
   - Shows top 5 offices
   - Green badges for counts

2. **SDPs with Most Targets**
   - Ranked by target count
   - Shows top 5 SDPs
   - Yellow badges for counts

### Activity Feed
- **Recent Activity** list
- Shows last 10 actions
- Includes: user, action, module, timestamp
- Real-time system activity monitoring

### System Info Panel
- Comprehensive statistics summary
- Overall progress bar
- System status indicator
- Quick reference for key metrics
